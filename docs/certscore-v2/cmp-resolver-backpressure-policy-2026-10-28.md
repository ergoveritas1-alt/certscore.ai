## Shared repair

An action-search geometry timeout previously ended the caller's wait while its
browser evaluation continued. A subsequent search pass could start another
evaluation in the same frame. A deterministic browser fixture reproduced this
overlap before the repair.

Accept and Reject canonical search now request a per-frame pending-read guard.
The slot remains occupied until the actual evaluation fulfills or rejects, even
if the caller times out. Later search passes skip that busy frame and retain
incomplete coverage. A completed late result is discarded; the next available
pass reads fresh state. Frames and pages have independent slots, so an unrelated
busy frame does not suppress a fresh main-frame control. Passive geometry
callers keep their existing behavior.

The diagnostic classifier also checks captured versus expected frame counts.
An empty partial inventory cannot become a control-absence diagnostic. Positive
retained candidates remain usable only through the unchanged live binding,
uniqueness, label, visibility, hit-target, authorization and semantic-proof gates.

There is no new read, retry, wait, action recipe, SDK call, capture window or
worker size. The change removes duplicate work. Expected recurring cost increment
is $0. Four targeted local public visits have a conservative $0.40 one-time
allowance. Existing contact holds, public-network guards, identity/region rules,
no-go stops and contact recording remain in force; the owner waived cooldown.
