## Explanation changes

The canonical CMP materializer now retains a typed, loader-bound privacy-link
inspection diagnostic even when it came from a registered CMP scope rather than
the separately marked same-origin public-page inspection. It requires the
completed original privacy-link checkpoint and typed outcomes; absent or
mismatched evidence stays unknown. An empty completed read is described as no
link captured in that inspection, never absence of a policy. A missing read is
explicitly described as no completed document-bound accessibility inspection.

These changes only explain existing unknowns. They do not grant checklist credit,
create findings, alter scores, qualify a control, authorize a click or infer an
obstruction. A retained deeper inspection takes precedence. The internal
assessment hash recipe is `independent_cmp_basic_facts.v12-privacy-diagnostics`;
this is not a new finding or legal interpretation policy.

The shared CMP report projection also carries the existing canonical policy
checklist's coverage explanation when the policy-link criterion is unassessed.
The PDF CMP matrix now includes the same factual evidence text for rows without
supplemental inventory. Previously it showed their labels/statuses while omitting
the explanations. Priority selection is unchanged.

Only the existing in-process materialization cache advances from v44 to v45.
Global projection v27 and compatible historical readers remain unchanged. There
is no repair/backfill, source rewrite, database migration or report-time
reconstruction. All new derivation uses already-retained evidence.
