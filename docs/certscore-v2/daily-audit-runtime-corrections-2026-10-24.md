# CertScore.ai retained-runtime audit corrections

The owner authorized local implementation on October 24, 2026. This work does
not authorize deployment, new public visits, historical rewrites or flag changes.

## Corrected boundaries

- The canonical scan-core no-go classifier recognizes the complete request
  rejection shell whose body says that the requested URL was rejected and asks
  the visitor to consult an administrator. The bounded, anchored pattern allows
  the shell's support reference and Go Back control. Quoted troubleshooting text,
  ordinary short pages and a rejected form submission do not match it.
- Passive lane diagnostics preserve the first HTTP response independently of
  final access classification. A later successful main-document response can
  establish representative access only when it precedes the same worker's final
  retained document and has its exact URL (excluding the HTTP-inapplicable
  fragment). Loader-bound positive content and the existing temporal/document
  checks remain required. Frames, subresources, stale/future responses and
  terminal no-go evidence cannot rescue the visit. Policy-lane terminal access
  remains independently assessed.
- Consent assessment persistence retains the exact final URL, including query
  and fragment. Existing normalized document comparisons continue to omit the
  fragment. A genuinely different child URL still fails parent binding.
- The coordinator and California projector share the existing
  `usable_starting_page_score.v1` original-runtime predicate. The retained final
  runtime snapshot is selected rather than an earlier navigation snapshot.
  Score weights, eligibility rules and policy versions are unchanged.
- A completed original runtime worker without a usable visit cannot produce a
  scored report merely because an independent consent session captured a page.
  The coordinator terminates the attempt as failed with
  `original_runtime_visit_unavailable`, cancels unfinished action/optional work,
  and retains the already-verified passive artifact pointers through the
  existing internal-only failed-terminal evidence contract. It adds no reads,
  retries, invocations, waits or independent publication. A known canonical
  no-go attempt may still publish its existing unscored disposition. Neither
  failure nor no-go invents missing evidence or a score.

The coordinator guard runs on new capture finalization. Historical persisted
assessments and report projections are read under their original versions;
they are not repaired during retrieval. Independent consent evidence is retained
and never transferred into runtime observations or the runtime score basis.

## Retained evidence and verification

Offline candidates use the daily audit's immutable, checksum/size-verified
bundles. The replay keeps original source hashes separate from hashes of local
candidate classifications. It preserves capture policy markers and routes
evidence through typed assessment, normalized concerns, concern policy,
unified/checklist projection and canonical scoring without database queries,
fresh visits or model calls.

The 21-case replay includes all seven flagged examples and 14 controls. The
request-rejection shell becomes no-go with null API/report scores. Weblio's
recovered original page receives California 93; 66Lottery's exact fragment binds
and receives California 88. Their EU scores stay 41 and 88. The two unusable
runtime cases fail rather than borrowing the independent consent visit. Existing
URL-binding and HTTP 522 repairs remain effective. All 14 controls preserve both
scores.

Fixtures cover the shell and negative controls, exact fragment binding,
successful recovery versus unrelated responses, stale/ambiguous runtime
snapshots, failed-attempt artifact retention, action cancellation and zero extra
artifact reads. Run evidence and final check results are retained under
`artifacts/daily-audit-local-fixes-2026-10-24/`.

## Audit interpretation

Audit procedure `2026-10-24.v3` requires alerts to distinguish historical affected
scans, current-code retained reproducibility and actual latest-producer
recurrence. Latest-release denominators and eligible trigger exposure must be
reported. A new reader serving an old report is not a new scanner recurrence.
Local replay does not establish production verification or close a deployed
issue without eligible ordinary scans.

## Cost and limits

Local work adds $0 AWS spend. Future incremental bounded classification and
failed-terminal pointer storage are conservatively estimated below $0.10/month

scans.
