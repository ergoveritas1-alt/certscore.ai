# CertScore.ai form and accessibility evidence integrity — October 31, 2026

Owner-authorized local implementation only. Deployment, production scans,
public visits, cloud queries, privacy actions and historical rewrites remain
outside this change. Existing windows, frame/field/byte caps and budgets remain.

Post-Accept structured capture restarts the existing sampling cadence when
confirmation supplies its already-authorized window even if the initial timer
expired before starting a sample. An in-flight evaluation owns scheduling;
continuation cannot create overlapping reads. A sample begun before the current
window cannot certify terminal coverage of that window. Frozen, cancelled,
changed-document and deadline guards remain. First-three-frame selection and
limited coverage are preserved; no cap increase or completeness inference.

Verified passive form-destination projection additionally joins the retained
scheme, hostname, port and path to one unambiguous network request ID. Stated
document/frame facts must agree with the main-document event. Response proof
must name the same endpoint and occur after the request within the scan window.
Query values and fragments remain excluded. This does not add native document
identity to old network rows, infer causality from timing, or upgrade declared
actions into observed transmissions. Runtime event token/field-HMAC binding and
canonical concern/policy/finding eligibility remain. Missing proof fails closed.

New accessibility examples carry optional bounded `selectorRetention`, version
`sanitized_selectors.v1`, with `unchanged` or `approximate` precision. The latter
includes privacy redaction, string truncation and frame/shadow-path truncation.
Quoted, unquoted and operator attribute values are stripped; escaped quotes or
brackets do not expose a trailing private value. Paths stay structurally nested.
Unchanged retention does not establish selector uniqueness or present-day
validity. Historical examples without metadata have unknown exactness. Web and
PDF/Word report content use shared qualified selector hints; verification asks
the developer to identify the affected element before editing. No executable
locator or privacy-sensitive attribute value is added. Existing accessibility
findings, scoring, counts and byte-budget allocation remain separate.

The additive optional field preserves old audit/projection versions and strict
bounded validation. It does not change the daily dashboard metric contract,
source pins, activation or sealed outputs. The shared fixture and focused
contract/capture/projection/presentation tests cover the new field. The permanent
retained regression gate includes scheduling, source joins, selector precision,
historical compatibility, form phase/export parity and accessibility scoring.
