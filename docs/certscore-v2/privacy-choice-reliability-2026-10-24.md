New `dom_opt_out_search.v3` is limited to the baseline runtime lane for the exact `https://gate.cc/` target and `https://celeb.gate.cc/` document. GPC, additional pages, combined/consent captures and other targets retain their existing behavior.

The existing atomic snapshot and its existing bounded retry now retain cached before/after URL and CDP loader bindings at the renderer operation's completion. The body, document URL, readiness and declared language come from that same operation. Existing sparse-body refreshes retain those facts together in their already scheduled read. A changed or missing loader, mismatched renderer URL, missing/unsupported language, loading document, failed read, replaced text or unbound fallback cannot supply the new proof. No new browser operation, navigation, wait, request, artifact fetch, worker, model call or capacity is introduced. The extra declared-language field stays private to the existing snapshot unless the new Gate proof qualifies.

Original runtime metadata and consent-owned evidence remain separate. The new proof retains its original text-read time/token rather than substituting metadata-finalization values. Later metadata must still match the original URL/token and remain within the visit. The existing coordinator carries this proof in runtime metadata without replacing the consent DOM or checkpoint. No privacy observation, choice state, inspection flag or original evidence packet is repaired.

New `sale_sharing_opt_out_scoped_search.v3` requires the exact target/document, one successful representative runtime lane, a parsed substantive declared-English public body, a nontruncated bounded search without positive or ambiguous wording, and unique original source records within the scan/lane times. A separately bound unusable consent body and its own no-evidence checkpoint remain an explicit limitation; their token is never borrowed for runtime absence. Missing evidence, unresolved policy choices, malformed/late source bindings, no-go attempts and unsupported captures remain Unknown. The original 100,000-character, eight-document, 160,000-character policy, 1 KiB body-proof and 2 KiB scoped-proof caps remain intact.

New `sale_sharing_opt_out_assessment.v4` carries this typed runtime scope through persistence -> normalized concern -> concern policy -> informational unified finding -> shared badge. A qualifying new read shows Not observed; **Captured runtime main-document text only**, the blocked consent capture and policy/control limitations remain behind the existing collapsed `…` assessment details. This does not establish full control coverage, governing-policy absence, California applicability or legal compliance. Independent scoring proof remains required: tests confirm that the runtime observation cannot create or cancel the existing nine-point finding. Older body/scoped/broad versions keep their original meanings.

Historical Gate has no new bound runtime proof and remains Unknown. A read-only replay matches all 100 prior states: **40 Observed / 29 Not observed / 31 Unknown** overall and **40 / 29 / 6** among the 75 reportable visits. All 75 canonical scores remain unchanged; 415 original retained bundles, manifests and text inputs were reverified unchanged. No original report, score, record or source artifact was rewritten. New qualifying behavior was tested using synthetic future-capture fixtures rather than backfilling the historical body.

Validation passed: 744 contract tests; 324 focused web/pipeline/scoring/UI/materialization tests; 33 capture/binding/inventory regression tests; the new source/language/canonical suite; and Lambda merge tests. The complete 173-test Lambda suite passed, and its two relevant metadata/merge tests were rechecked after adding the language guard. Contracts build and scan-core, web, validation-worker and Lambda typechecks passed. The previously documented unrelated advanced PDF/CSV-export assertion remains excluded and unchanged. Coverage includes same-URL reloads, delayed metadata consumption, missing/changed CDP identity, wrong source lanes/targets, unsupported languages, unusable/loading/truncated bodies, ambiguity, policy conflicts, malformed and missing checkpoints, unchanged historical states, scoring eligibility and compact expanded-only scope.

Testing incident: an initial fixture used an intercepted redirect whose destination bypassed browser routing, causing two unintended Gate page loads. No privacy choice, form submission, CertScore.ai scan job, production write or historical rewrite occurred. The fixture was corrected to disable networking before page creation and navigate directly to synthetic intercepted bytes; the final browser test passes with one intercepted request and zero actions. Temporary local capture directories were removed. This incident was disclosed during the work.

Both caps and the $1 approval threshold are respected; actual content mix, retention and report reads require re-estimation. This is a planning estimate, not live billing or a universal worst-case ceiling. No deployment, flag change, AWS invocation, historical rewrite or increased configured budget occurred.
