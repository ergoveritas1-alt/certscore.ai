verification, the full release gate and AWS deployment if all checks pass.

The Lambda lane's `representative_page` navigation diagnostic is not sufficient
to overturn a corroborated no-go from an independent lane. At the canonical
lane-reconciliation boundary, require positive retained runtime document content:

- Use the latest original runtime DOM snapshot, with its CDP loader identity,
  exact URL (including query), artifact identity and bounded capture time.
- Reject ambiguous latest snapshots and conflicting later document-bound
  accessibility or collection-inventory observations.
- Accept the existing substantive-text bounds (180 characters and 24 words), or
  a retained title together with nonempty body text for short and non-English
  pages. A title alone or a bare loading message does not qualify.
- A non-text page may use an already-retained positive visual assessment and
  available non-placeholder screenshot bound to the same runtime document.
  Screenshot availability, canvas presence or HTTP success alone is insufficient.

Keep existing execution/coverage and explicit no-go checks. Missing positive
runtime proof does not create a no-go: it simply cannot cancel an independently
corroborated no-go. Preserve valid independent visits, ordinary short-page
reportability, consent-lane ownership, and the single canonical publication path.
Do not infer a new finding or scoring effect from the helper. Downstream failure
and score suppression continue to consume the existing canonical no-go decision.

Historical packets and materialized reports remain unchanged. The changed
scanner build is the deployment boundary. This repair adds no browser capture,
wait, retry, model call, storage field, worker capacity or recurring cost.
