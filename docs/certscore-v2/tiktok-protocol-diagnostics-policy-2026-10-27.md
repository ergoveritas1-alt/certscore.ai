## Local implementation

`bounded_ca_body_diagnostic.v1` adds optional closed input-kind and parser-stage
metadata to existing proof contracts. It uses existing ephemeral reads and
preserves byte, field, depth, inspection and proof limits. It retains no body
values, raw payload, unknown key path or exception message. Diagnostic callbacks
cannot change decoding if an observer throws. Later header framing, encoding and
MIME failures receive their own stage instead of a false success stage. Legacy
proofs remain valid without metadata. Specialized decoders only expose the
stages their current entry points provide; a stage does not identify a rejected
field or prove a root cause.

Request payload field-name metadata now retains at most 32 safe token names;
opaque/base64/array bodies cannot masquerade as a form field name. Original body
bytes remain ephemeral for existing analysis. No new browser read or wait is
introduced. Estimated additional recurring JSON storage is below $0.25/month at
100,000 scans; this estimate was disclosed before proceeding.

The offline audit queue requires a valid typed proof, unique event/request join,
exact URL hash, method, time and main-document token. Source-binding problems,
processing declarations, existing supported qualification and unresolved
protocols remain separate. Classification never creates findings. The CLI also
verifies original canonical scan identity and emits parent/worker receipts.
These helper changes are not installed into the pinned daily audit tools.

Future deployment would require compatible producer and consumer contracts to be
released together. This document is not deployment authorization.
