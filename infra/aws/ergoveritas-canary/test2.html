Privacy and accessibility canary

Owned synthetic test page. It loads optional technologies before a choice and suppresses Pinterest advertising when browser GPC is enabled, while other identified advertising requests deliberately continue. No account or transaction state is involved.

Cookie choices

Optional analytics, advertising, session replay, and product measurement are active on this test page before consent.

Notice at collection

This test page records identifiers and internet activity through optional analytics, advertising, session replay, and product measurement requests. Before a choice is saved, those requests may be sent to the named providers. Browser GPC prevents the Pinterest advertising request and its test cookie, while Google, Meta and Microsoft advertising requests remain; a saved manual opt-out stops all future optional test requests in this browser.
